# 面向对象-三大特征

## 封装

### 为什么需要封装
开发时不需要了解类内部具体的实现，只使用少量的接口完成工作。这就需要我们隐藏类内部复杂的具体实现，只对外提供简单的接口。（高内聚，低耦合的含义就是上俩句话）
- 通过权限修饰符来实现的

### 权限修饰符

- java规定了四种权限修饰符（从小到大 ）
	- private 只在类内部可以访问
	- default（缺省） 类内部和同一个包可以访问
	- protect 类内部和同一个包以及不同包的子类可以访问
	- public 所有可以访问
- 这四种权限都可以修饰类的内部结构：属性，方法，构造器，内部类
- 但是修饰类只能用public 和 default
